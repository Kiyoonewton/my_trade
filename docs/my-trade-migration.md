# Migration from my_trade to KioTrad

KioTrad is introduced as the successor implementation.
Both original Git histories and commit dates are preserved.
Older my_trade commits do not imply that KioTrad existed at those dates.

This migration copies source code only, without databases,
raw archives, credentials or changes to running services.

Original PR records remain in their respective GitHub repositories.
Merge this branch using a merge commit, not squash or rebase.
